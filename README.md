# 🌿 Weather Tracker

A simple weather app that shows real-time weather information for any city.

## ✨ Features

🌤 Search weather by city

🌡 Shows temperature, humidity, wind, etc.

📜 Search history (saved in browser)

🌄 Background changes based on weather

📱 Responsive design

## 🛠 Technologies Used

HTML

CSS

JavaScript

OpenWeather API

## 📁 Files
index.html
style.css
script.js

## 🔑 How to Run

Open the project folder

Add your API key in script.js

Open index.html in browser (or use Live Server)

##⚠️ Note

Enter city names only (like Delhi, Mumbai)

API key may take some time to activate
